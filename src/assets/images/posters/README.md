## Notas
- La imagen se recorta con `object-fit: cover` al marco de la tarjeta (la proporción de arriba es la del marco).
- Encima de la imagen quedan las etiquetas (`Poster 01`, título, autora). Si estorban en alguna foto, avísame y las oculto o les subo el fondo.
- Formato recomendado: `.jpg` optimizado (o `.webp`). Puedes usar otro nombre, solo ajusta el `src` en `index.html`.
