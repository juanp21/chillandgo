# Foto del Hero

Coloca aquí tu foto principal con el nombre exacto:

```
hero-photo.jpg
```

**Recomendaciones:**
- Orientación horizontal, mínimo 1920×1080px (idealmente 2400×1350px o más para pantallas retina).
- Formato `.jpg` optimizado (o `.webp` si prefieres mejor compresión — solo actualiza la extensión en `index.html`).
- Peso ideal: menos de 500KB. Usa [squoosh.app](https://squoosh.app) para comprimir sin perder calidad visible.
- Si la foto es muy clara, el título "CHILL&GO" (naranja con contorno rojo) puede perder contraste — evita fotos muy blancas/brillantes en el centro.

Una vez que la imagen esté aquí, ve a `index.html`, busca el comentario `REEMPLAZA AQUÍ TU FOTO O VIDEO REAL` dentro de `<section id="top">`, y descomenta la línea de `<img>` (Opción A).

Si vas a usar un video en su lugar, esta misma foto sirve como `poster` (la imagen que se ve mientras el video carga).
